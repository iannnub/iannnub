## Projects

### [JemberTrip: AI Tourism Platform](https://github.com/iannnub/jembertrip)
**React.js, Vite, FastAPI, PostgreSQL, ChromaDB, Scikit-Learn, LangChain**

Built a multilingual RAG-powered chatbot (LangChain + external LLMs via HuggingFace/Groq) that answers Jember tourism queries in Indonesian, Javanese, or Madurese. Asynchronous FastAPI backend with PostgreSQL for real-time clickstream tracking and ChromaDB for vector-based semantic search. Hybrid recommendation engine (Content-Based + Collaborative Filtering) hit Precision@6 56.55% and delivered Top-N recommendations in under 1 second. Used by 1,500+ users over 3 months. Later became my undergraduate thesis.

### [SIMPRESMA: Faculty Achievement Management](https://github.com/iannnub/simpresma-backend)
**Laravel 11, React 18 (TypeScript), MySQL, Laravel Sanctum**

Management system for UNEJ Computer Science Faculty to track academic achievements. Custom RBAC system for different stakeholders (Wadek, Tendik, Verifikator, Students). Data export engine (Excel/CSV) and Telegram Bot API for real-time notifications. Currently integrating with campus SSO/CAS system.

### [SiPresensi: Multi-Tenant Attendance SaaS](https://github.com/iannnub/sipresensi)
**Laravel 12, MySQL, Redis, WebSocket**

Multi-tenant attendance platform with subdomain-based tenant isolation. IoT/fingerprint device integration, real-time WebSocket dashboards, and automated WhatsApp notifications. In pilot testing with the university.

### [KakYo Lesson: Music Lesson Management](https://github.com/iannnub/music-project)
**PHP (custom MVC), MySQL/MariaDB, HTML5 WebRTC, Geolocation API**

Music course management system with GPS-geofenced camera attendance. Live webcam capture (HTML5 WebRTC) + Haversine-based radius validation (100m) to prevent remote check-ins. Automated payroll: Rp30,000/hour with Rp5,000 penalty per 10 minutes late. Live and in daily operation, fully replaced manual attendance and payroll tracking.

### [Javapedia: Digital Business Platform](https://github.com/iannnub/javapedia)
**PHP, MySQL, Midtrans Payment Gateway, JavaScript**

Digital service business I built and ran for 4.5 years, processing ~30 orders daily. Integrated Midtrans payment gateway and automated financial reconciliation for audit-ready records. Managed team of 6 while handling system reliability and live-chat support.

### [Wuluhan Healthcare: Pharmacy Inventory System](https://github.com/iannnub/puskesmas)
**PHP (native), MySQL/MariaDB via PDO, Bootstrap 4**

Inventory system built during internship, replacing manual paper tracking. Used across 9 clinical units (General, Dental, HIV, TB, TBS, MCH, Emergency, Inpatient, Pharmacy). Extensive testing for data integrity on prescription and medicine stock tracking.
