## Featured Projects

### [Puput LPG: Distribution, 4-Basket Inventory & Accounting ERP](https://github.com/iannnub/puput-lpg)
**Next.js 15 (App Router, Server Actions), TypeScript, Supabase PostgreSQL 16 (RLS & Atomic RPC), React-PDF, ExcelJS**  
🔗 **Live Demo:** [puput-lpg.vercel.app](https://puput-lpg.vercel.app)

Integrated operational and accounting web system for an LPG distribution agency. Tracks cylinder inventory across 4 physical states (`gudang_isi`, `gudang_kosong`, `gudang_bocor`, `dipinjam_mitra`) with zero direct table mutations—all stock, receivable, cashflow, and payroll mutations execute atomically through 14 PostgreSQL RPC functions using `SELECT ... FOR UPDATE` row-level locking to prevent race conditions. Features credit-limit & overdue tempo locks with Owner password override, FIFO employee kasbon deduction, A5 PDF invoice/payslip generation, and accrual vs. cash profit-and-loss reporting.

### [SIMPRESMA: Faculty Student Achievement & SKS Conversion System](https://github.com/iannnub/simpresma-backend)
**Laravel 11, React 18, TypeScript, MySQL, GAPURA UNEJ SSO (OAuth 2.0 / OIDC), Zustand, TanStack Query, Telegram Bot API**  
🔗 **Repositories:** [Backend API](https://github.com/iannnub/simpresma-backend) • [Frontend SPA](https://github.com/iannnub/simpresma-frontend)

Academic achievement management and SKS credit conversion system for the Faculty of Computer Science, Universitas Jember (FASILKOM UNEJ). Fully integrated with **GAPURA UNEJ SSO** (OAuth 2.0 & OpenID Connect) with anti-CSRF state protection and smart auto-provisioning. Implements dynamic 5-role RBAC (Mahasiswa, Dosen Verifikator, Tendik, Wakil Dekan I, Super Admin) with instant role-switching, immutable SKS conversion matrix snapshots, Excel reporting, and real-time push notifications via `@simpresma_unej_bot`. Backed by 82 PHPUnit tests (556 assertions) and 23 Vitest unit tests.

### [Platinum Project: Wedding & Event Decoration Management](https://github.com/iannnub/platinumproject-frontend)
**Laravel 12, Next.js 16 (App Router), React 19, TypeScript, MySQL, Sanctum, Leaflet/OpenStreetMap, TanStack Query, Recharts**  
🔗 **Live Demo:** [platinumproject-frontend.vercel.app](https://platinumproject-frontend.vercel.app) • **Repos:** [Frontend](https://github.com/iannnub/platinumproject-frontend) • [Backend](https://github.com/iannnub/platinumproject-backend)

Admins manage schedules, DP/settlement payment logs, per-event RAB operational expenses, 12-month cashflow analytics, and net profit margins with PDF and Excel export.

### [JemberTrip: AI Tourism Platform & Multilingual RAG Chatbot](https://github.com/iannnub/jembertrip)
**React, Vite, FastAPI, Python, PostgreSQL, ChromaDB, Scikit-Learn, LangChain**
